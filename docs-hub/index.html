LocalGovy · Dispensary demos

Nine unique dispensary templates

Browser demos of the Expo templates. Each app keeps the same core features (age gate, shop, cart, orders, AI, loyalty, pickup) with a distinct visual thesis. Auth is bypassed in these demos so you can explore the UI immediately.

Walkthrough

  1. Open the hub (this page) at https://localgovy.github.io/dispotemplates/
  2. Pick a template card below — each opens in a phone frame (mobile-sized preview).
  3. Interact inside the phone: splash → age gate (any 19+ DOB) → Home / Shop / Cart / Orders / Account.
  4. Use Open full screen if you want the raw web demo, or All templates to return here.
